1

Level 1: Agent 核心概念与 System Prompt 约束 基础入门

理解 LLM 的系统指令 (System Prompt) 如何确立安全边界，禁止 LLM 越权生成代码或直接操作场景。

  • 研读安全边界 Prompt 规则
    在 eee_agent/system_prompt.py 中学习强约束规则的写法：
    # eee_agent/system_prompt.py 核心片段 BASE_PROMPT = """ SECURITY BOUNDARY - The available Runtime tools are: scene_status, query_scene, inspect_workspace... - Never invent a tool, call direct HOM/Python, or assume a scene write is possible. - A modeling request must first become a typed proposal/ChangeSet through propose_modeling. """
2

Level 2: LangChain / DeepAgents 自定义 Tool 编写 工具开发

掌握如何在 LangChain / DeepAgents 中使用 `@tool` 装饰器编写只读工具并定义强类型参数规范 (Pydantic / Type Hint)。

  • 看懂 `@tool` 装饰器与 Tool 参数 Schema
    参考 eee_agent/runtime/agent_tools.py，编写自己的 Tool：
    from langchain_core.tools import tool @tool def query_scene_node_count(parent_path: str = "/obj") -> str: """返回指定节点路径下的子节点总数 (仅读)""" # 调用 Secure Bridge 执行安全查询 result = bridge.query({"action": "count_nodes", "path": parent_path}) return f"Node count under {parent_path}: {result['count']}"
3

Level 3: 工业级 ChangeSet 修改提案模式 安全范式

理解“Proposal -> Approval -> Transactional Apply”的架构设计，杜绝 LLM 盲目修改生产环境。

  • 理解 ChangeSet 强类型数据结构
    在 eee_agent/changesets/ 中查看 typed ChangeSet 契约：
    # 每一个修改都是强类型的 Action 对象，而非随意拼接的 Python 代码 { "changeset_id": "cs_20260722_001", "intent": "Create parametric sci-fi base", "actions": [ {"op": "create_node", "type": "geo", "name": "building_base"}, {"op": "set_parm", "node": "building_base", "parm": "height", "val": 12.5} ] }
4

Level 4: 离线自动化测试网与调试 实战演练

使用 pytest 运行离线测试套件，在不连接 LLM 和 Houdini 的情况下验证 Agent 的逻辑健全性。

  • 运行离线 PyTest 套件
    打开 Powershell 或 CMD 终端，输入以下命令：
    uv run --extra eval pytest -q
