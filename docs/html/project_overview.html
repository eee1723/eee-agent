💡 什么是 EEE Procedural Modeling Agent？

这是一个专门用于 3D 程序化建模（Procedural / Parametric Modeling） 的 AI Agent 项目。它打破了传统 AI 只生成静态 3D 网格的局限，能够像资深 3D 艺术家一样，在 SideFX Houdini 21 中规划、搭建原生 SOP 节点网络与 VEX 代码、读取几何体反馈、自动排错纠错，并将关键参数暴露为 Tunables，实现“可无损调整”的程序化资产生成。

🏗️ 三进程隔离设计 (Three-Process Isolation)

为了保证 Houdini 宿主环境的绝对稳定与安全，项目采用了严格的 三进程隔离架构，避免 Agent 依赖污染 Houdini 自带的 Python 环境：

进程 1: Houdini 21 宿主 PySide6 GUI

运行于 Houdini 内部。提供三面板交互界面与 Strict Secure Bridge。

⇄
进程 2: WebSocket Runtime Loopback Server

独立持久化服务进程。处理鉴权 Bearer Token、SQLite 会话与状态同步。

⇄
进程 3: DeepAgents 智能体 Python 3.11 .venv

大脑核心。运行 deepagents 框架、可靠性中间件与 LLM 交互。

🛡️ 核心工程突破与安全机制

🔒 严格的 ChangeSet 写入边界

  • 无 Raw Write 工具: LLM 永远无法直接操作 Houdini 节点网络。
  • Typed Proposal: Agent 只能输出强类型的修改建议 (ChangeSet Proposal)。
  • Explicit Approval: 必须由用户在 Houdini GUI 面板中手动确认批准。
  • Transactional Apply: 事务型原子执行，带 Receipt 回执与断点恢复。

⚖️ 确定性质量闸门 (Quality Gate)

  • Spec/Graph/Cook 校验: 验证节点图中是否存在断路、Cook 报错。
  • Geometry 几何断言: 检查点/面数量、Bounding Box 边界框、法线规范。
  • Parameter Sensitivity: 验证参数调整时模型是否正常形变。
  • 硬性阻断: 只有确定性校验全部通过，才允许交付资产。
